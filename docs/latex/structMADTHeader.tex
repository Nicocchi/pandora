\doxysubsection{Detailed Description}
Multiple APIC Description Table (MADT) header. 

Follows the standard \doxylink{structACPISDTHeader}{ACPISDTHeader} and provides the default Local APIC base address as reported by firmware. Variable-\/length MADT entries immediately follow this header and describe each APIC component present in the system.

The entries are walked sequentially using each entry\textquotesingle{}s length field to advance to the next entry.

\begin{DoxyNote}{Note}
Must be parsed as a packed struct to avoid compiler padding.
\end{DoxyNote}
