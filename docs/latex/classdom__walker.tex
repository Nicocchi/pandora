\doxysubsection{Detailed Description}
This is the main class for the dominator walker. It is expected that consumers will have a custom class inheriting from it, which will over ride at least one of before\+\_\+dom\+\_\+children and after\+\_\+dom\+\_\+children to implement the custom behavior.
