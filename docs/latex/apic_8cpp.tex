void Init\+APIC (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Parses ACPI tables and initializes the APIC subsystem. 

Performs the following steps:\+


\begin{DoxyEnumerate}
\item Retrieves the RSDP address from the Limine bootloader response.
\item Walks the XSDT (ACPI 2.\+0+) or RSDT (ACPI 1.\+0) to locate the MADT.
\item Parses all MADT entries to discover Local APIC and I/\+O APIC addresses and records any Interrupt Source Overrides.
\item Maps the Local APIC and I/\+O APIC MMIO regions into virtual memory by splitting existing huge page mappings in the kernel page tables.
\end{DoxyEnumerate}

Must be called before \doxylink{apic_8h_a7784208db7a116e5e2250ef1a14a1d9a}{Init\+LAPIC()}, \doxylink{apic_8h_adc9bb3dd155adce97361c2fbac6e2732}{Init\+IOAPIC()}, or \doxylink{idt_8cpp_a1f7ab111305cf00cb8285c8241dd6692}{Disable\+PIC()}. Panics if the RSDP, HHDM, MADT, or I/\+O APIC cannot be found. \Hypertarget{apic_8cpp_adc9bb3dd155adce97361c2fbac6e2732}\index{apic.cpp@{apic.cpp}!InitIOAPIC@{InitIOAPIC}}

void Init\+IOAPIC (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Initializes the I/\+O APIC and configures interrupt routing. 

Routes the PIT timer IRQ (IRQ 0) to IDT vector 32 on CPU 0, taking into account any Interrupt Source Override present in the MADT that remaps IRQ 0 to a different GSI. Must be called after \doxylink{apic_8h_a409b2660b7120cd593269c657db55902}{Init\+APIC()} has mapped the I/\+O APIC MMIO region and populated the ISO table. \Hypertarget{apic_8cpp_a7784208db7a116e5e2250ef1a14a1d9a}\index{apic.cpp@{apic.cpp}!InitLAPIC@{InitLAPIC}}
