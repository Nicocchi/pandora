\doxysubsection{Detailed Description}
MADT entry describing an I/\+O APIC (type 1). 

Provides the physical base address of an I/\+O APIC and its Global System Interrupt (GSI) base, which is the first GSI number that this I/\+O APIC handles. Systems with multiple I/\+O APICs assign non-\/overlapping GSI ranges to each unit.

Must be parsed as a packed struct to avoid compiler padding.
