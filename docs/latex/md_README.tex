   \hypertarget{md_README_autotoc_md2}{}\doxysection{\texorpdfstring{Overview}{Overview}}\label{md_README_autotoc_md2}
{\bfseries{Pandora OS}} is a custom 64-\/bit operating system designed for x86\+\_\+64 systems. The project focuses on building a modular kernel architecture while exploring concepts such as:\+


\begin{DoxyItemize}
\item Bootloading
\item Memory management
\item Multitasking
\item Hardware drivers
\item Filesystems
\item Graphics and UI systems
\end{DoxyItemize}

The operating system currently boots using the {\bfseries{Limine Bootloader}} and is being developed as an educational and hobby systems programming project.

\hypertarget{md_README_autotoc_md8}{}\doxysection{\texorpdfstring{Why Pandora OS?}{Why Pandora OS?}}\label{md_README_autotoc_md8}
Pandora OS was created as a hobby and educational operating system project focused on learning low-\/level systems programming and kernel development.

The project serves as a hands-\/on environment for exploring:\+


\begin{DoxyItemize}
\item x86\+\_\+64 architecture
\item Boot protocols and early kernel initialization
\item Memory management
\item Hardware drivers
\item Interrupts and multitasking
\item Filesystems and executable formats
\item Graphics and rendering systems
\end{DoxyItemize}

Rather than aiming to compete with existing operating systems, Pandora OS is designed as a long-\/term learning platform and experimental kernel architecture project.

The goal is to better understand how modern operating systems function internally by building components from the ground up.

\hypertarget{md_README_autotoc_md26}{}\doxysubsection{\texorpdfstring{Building the Cross Compiler}{Building the Cross Compiler}}\label{md_README_autotoc_md26}
From the root project directory:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{./toolchain.sh}

\end{DoxyCode}


This script will:\+


\begin{DoxyEnumerate}
\item Download {\bfseries{binutils}} and {\bfseries{GCC}}
\item Configure the cross-\/compilation toolchain
\item Build the compiler
\item Install it into the {\ttfamily toolchain/\+} directory
\item Verify the compiler installation
\end{DoxyEnumerate}\hypertarget{md_README_autotoc_md27}{}\doxysubsubsection{\texorpdfstring{Toolchain Script Options}{Toolchain Script Options}}\label{md_README_autotoc_md27}

{\ttfamily parallel}  &Enable parallel compilation jobs  \\

Example:\+


\begin{DoxyCode}{0}
