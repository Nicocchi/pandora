 Provides structural layouts for the GDT pointer register (GDTR) and modern 64-\/bit segment descriptors. It establishes standard flat-\/model kernel and user space segments required to clear the processor\textquotesingle{}s real-\/mode inheritance during x86\+\_\+64 initialization.
