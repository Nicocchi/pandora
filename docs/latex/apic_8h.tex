Advanced Programmable Interrupt Controller (APIC) structures and definitions.

Defines the data structures and function declarations required to initialize and operate the x86\+\_\+64 Local APIC and I/\+O APIC subsystems.

This header covers:\+


\begin{DoxyItemize}
\item ACPI Root System Description Pointer (RSDP) parsing structures
\item ACPI System Description Table (SDT) header layout
\item Multiple APIC Description Table (MADT) header and entry structures
\item Interrupt Source Override (ISO) storage for GSI remapping
\item Local APIC and I/\+O APIC initialization and EOI signaling
\end{DoxyItemize}

The APIC subsystem replaces the legacy 8259 Programmable Interrupt Controller (PIC) and is required for symmetric multiprocessing (SMP) support.

Interrupt routing through the I/\+O APIC is configured using the MADT entries provided by ACPI firmware, including any Interrupt Source Overrides that remap legacy ISA IRQs to different Global System Interrupt (GSI) lines.

void Init\+APIC (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Parses ACPI tables and initializes the APIC subsystem. 

Performs the following steps:\+


\begin{DoxyEnumerate}
\item Retrieves the RSDP address from the Limine bootloader response.
\item Walks the XSDT (ACPI 2.\+0+) or RSDT (ACPI 1.\+0) to locate the MADT.
\item Parses all MADT entries to discover Local APIC and I/\+O APIC addresses and records any Interrupt Source Overrides.
\item Maps the Local APIC and I/\+O APIC MMIO regions into virtual memory by splitting existing huge page mappings in the kernel page tables.
\end{DoxyEnumerate}

Must be called before \doxylink{apic_8h_a7784208db7a116e5e2250ef1a14a1d9a}{Init\+LAPIC()}, \doxylink{apic_8h_adc9bb3dd155adce97361c2fbac6e2732}{Init\+IOAPIC()}, or \doxylink{idt_8cpp_a1f7ab111305cf00cb8285c8241dd6692}{Disable\+PIC()}. Panics if the RSDP, HHDM, MADT, or I/\+O APIC cannot be found. \Hypertarget{apic_8h_adc9bb3dd155adce97361c2fbac6e2732}\index{apic.h@{apic.h}!InitIOAPIC@{InitIOAPIC}}

void LAPICEoi (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Signals End Of Interrupt to the Local APIC. 

Must be called at the end of every hardware interrupt handler to allow the Local APIC to accept further interrupts. Writing any value to the EOI register acknowledges the current interrupt.

\begin{DoxyNote}{Note}
Do NOT call this for NMIs, SMIs, INIT, or spurious interrupts.
