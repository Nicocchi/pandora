Provides globally shared constants, descriptor selectors, and architecture-\/level resources used throughout the kernel.

This header primarily contains:\+
\begin{DoxyItemize}
\item GDT selector definitions
\item Privilege-\/level segment constants
\item Early kernel bootstrap resources
\item Shared low-\/level CPU infrastructure data
\end{DoxyItemize}

The selector values defined here correspond directly to the descriptor layout installed by the kernel Global Descriptor Table (GDT).
