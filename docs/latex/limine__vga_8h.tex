\doxysubsection{Detailed Description}
Driver interface for the Limine graphics framebuffer and PSF1 text rendering.

Provides core definitions, color palettes, and structures required to manage the Limine bootloader\textquotesingle{}s graphical framebuffer response. Includes explicit type mapping for PC Screen Font (PSF1) parsing to enable kernel-\/space text rendering and terminal emulation.
