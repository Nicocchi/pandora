~\newline
 Defines the core data structures used for x86\+\_\+64 interrupt handling, including IDT gate descriptors, the IDTR register structure, and the interrupt stack frame passed from low-\/level assembly interrupt stubs into the higher-\/level C++ interrupt dispatcher.

The IDT is responsible for routing CPU exceptions, hardware IRQs, and software interrupts to their respective interrupt service routines (ISRs).
