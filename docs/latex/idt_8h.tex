Defines the core x86\+\_\+64 interrupt management structures and interfaces used by the Pandora OS kernel.

This module provides:\+
\begin{DoxyItemize}
\item Interrupt Descriptor Table (IDT) gate definitions
\item IDTR register layout definitions
\item CPU interrupt stack frame structures
\item Interrupt handler registration interfaces
\item CPU interrupt control helpers
\item Legacy PIC compatibility interfaces
\end{DoxyItemize}

The IDT is responsible for routing:\+
\begin{DoxyItemize}
\item CPU exceptions (vectors 0-\/31)
\item Hardware interrupts (IRQs)
\item Software interrupts
\item APIC-\/routed interrupt vectors
\end{DoxyItemize}

Interrupts originate from low-\/level assembly ISR stubs which preserve processor state before transferring execution into the higher-\/level C++ interrupt dispatcher.

In APIC mode, hardware interrupt acknowledgement is performed through the Local APIC End Of Interrupt (EOI) register instead of the legacy 8259 PIC controller.

The structures defined in this file must remain ABI-\/compatible with:\+
\begin{DoxyItemize}
\item x86\+\_\+64 interrupt frame layouts
\item ISR assembly stubs
\item the {\ttfamily lidt} instruction requirements
\end{DoxyItemize}

A single Interrupt Descriptor Table (IDT) gate descriptor. 

Represents a 16-\/byte interrupt gate entry in the x86\+\_\+64 IDT.

Each descriptor defines:\+
\begin{DoxyItemize}
\item the target interrupt service routine address
\item the target code segment selector
\item gate privilege attributes
\item optional Interrupt Stack Table (IST) switching
\end{DoxyItemize}

The processor indexes this structure using the interrupt vector number during interrupt or exception dispatch.

Structure layout follows the Intel-\/defined 64-\/bit interrupt gate format. \Hypertarget{idt_8h_a7191695ad6f126dd6d33f792fd6b7547}\index{idt.h@{idt.h}!IDTPtr@{IDTPtr}}

CPU register state captured during interrupt dispatch. 

This structure represents the complete processor state preserved by the low-\/level ISR assembly stubs before control is transferred into the C++ interrupt dispatcher.

The layout MUST exactly match the push order implemented in {\ttfamily \doxylink{idt_8asm}{idt.\+asm}}. Any modification to this structure requires corresponding assembly updates.

The frame contains:\+
\begin{DoxyItemize}
\item General-\/purpose registers
\item Interrupt vector number
\item CPU-\/generated error code
\item Automatically-\/pushed processor state
\end{DoxyItemize}

The final fields ({\ttfamily rip}, {\ttfamily cs}, and {\ttfamily rflags}) are automatically pushed by the processor during interrupt or exception entry.

For privilege-\/level transitions, the CPU may additionally push:\+
\begin{DoxyItemize}
\item RSP
\item SS
\end{DoxyItemize}

Those fields are currently omitted because interrupts originate only from ring 0 kernel execution. \Hypertarget{idt_8h_adccf2dbfed381ac42b105efacb4fe4df}\index{idt.h@{idt.h}!InterruptHandler@{InterruptHandler}}
