\doxysubsection{Detailed Description}
Common header for all variable-\/length MADT entries. 

Every MADT entry begins with this two-\/byte header. The type field identifies the entry kind and the length field gives the total byte size of the entry, allowing the MADT walker to skip unknown types.

\begin{DoxyNote}{Note}
Must be parsed as a packed struct to avoid compiler padding. 
\end{DoxyNote}
