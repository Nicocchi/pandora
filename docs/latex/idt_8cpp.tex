\doxysubsection{Detailed Description}
Interrupt Descriptor Table (IDT) initialization and interrupt dispatching.

~\newline
 Implements the x86\+\_\+64 Interrupt Descriptor Table subsystem, including:\+


\begin{DoxyItemize}
\item IDT entry creation and initialization
\item PIC remapping for hardware IRQ support
\item CPU exception handling and diagnostics
\item IRQ acknowledgement through End Of Interrupt (EOI) signaling
\item Interrupt dispatch bridging between assembly ISR stubs and C++ handlers
\end{DoxyItemize}

The IDT is loaded through the {\ttfamily lidt} instruction and used by the processor to dispatch exceptions and interrupts into kernel-\/defined handlers.

Hardware IRQs are remapped away from CPU exception vectors using the legacy Programmable Interrupt Controller (PIC).
