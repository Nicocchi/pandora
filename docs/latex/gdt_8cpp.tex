\doxysubsection{Detailed Description}
Global Descriptor Table (GDT) and Task State Segment (TSS) initialization routines.

Implements construction and installation of the kernel\textquotesingle{}s x86\+\_\+64 descriptor table infrastructure.

This module is responsible for:\+
\begin{DoxyItemize}
\item Building the Global Descriptor Table (GDT)
\item Creating kernel and user segment descriptors
\item Constructing the 64-\/bit Task State Segment (TSS) descriptor
\item Initializing the Task State Segment structure
\item Loading the GDTR register using {\ttfamily lgdt}
\item Loading the Task Register (TR) using {\ttfamily ltr}
\item Reloading CPU segment registers
\end{DoxyItemize}

The initialized GDT establishes a flat-\/memory segmentation model suitable for modern x86\+\_\+64 long mode kernels.

Although segmentation is mostly disabled in long mode, descriptor tables remain required for:\+
\begin{DoxyItemize}
\item Privilege level separation
\item System segment management
\item Ring transitions
\item Interrupt stack switching
\item Task State Segment support
\end{DoxyItemize}

The TSS is configured to provide:\+
\begin{DoxyItemize}
\item Ring 0 kernel stack switching
\item Interrupt Stack Table (IST) infrastructure
\item Future userspace transition support
\end{DoxyItemize}

uint8\+\_\+t kernel\+\_\+stack\+[16384]\+}



Primary kernel privilege-\/transition stack. 

This stack is used as the initial ring 0 stack during CPU privilege transitions from user mode into kernel mode.

The top of this stack is loaded into the Task State Segment rsp0 field during GDT/\+\+TSS initialization.

Stack growth direction:\+
\begin{DoxyItemize}
\item x86\+\_\+64 stacks grow downward toward lower memory addresses
\item The initial stack pointer is therefore the END of this array
