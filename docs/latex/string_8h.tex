\doxysubsection{Detailed Description}
Freestanding standard utility functions for raw memory and string diagnostics.

Implements clean-\/room equivalents of standard C library memory transformations ({\ttfamily \doxylink{string_8h_a2608ce0c6e7fd7f19fadeee9b01642e2}{memcpy}}, {\ttfamily \doxylink{string_8h_a313175102214d45434bf045db18dddf0}{memset}}, {\ttfamily \doxylink{string_8h_a340d11725e5c81a874f508fbcdf1c5ef}{memmove}}, {\ttfamily \doxylink{string_8h_a9e6df54ee04e18a3772335580e2ed872}{memcmp}}) and primitive null-\/terminated ASCII string processing rules. Designed specifically to execute without a standard C library runtime environment.
