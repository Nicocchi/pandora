\doxysubsection{Detailed Description}
x86\+\_\+64 Global Descriptor Table (GDT) and Task State Segment (TSS) management. 

Provides structures, descriptor encoders, and initialization routines for x86\+\_\+64 segmentation infrastructure used by the kernel.

This subsystem configures:\+
\begin{DoxyItemize}
\item Global Descriptor Table (GDT)
\item Kernel and user privilege segments
\item Task State Segment (TSS)
\item Ring transition stack switching
\item Interrupt Stack Table (IST) support
\end{DoxyItemize}

Although segmentation is largely disabled in x86\+\_\+64 long mode, valid descriptor tables remain mandatory for:\+
\begin{DoxyItemize}
\item Privilege level enforcement
\item System descriptors
\item Interrupt/\+syscall transitions
\item Task register management 
\end{DoxyItemize}

Standard 64-\/bit GDT segment descriptor. 

Represents the legacy 8-\/byte segment descriptor format used by the x86 processor family. Even though segmentation is largely disabled in x86\+\_\+64 long mode, valid descriptors are still required for:\+


\begin{DoxyItemize}
\item Kernel and user privilege levels
\item Code segment execution metadata
\item System descriptors such as the TSS
\item Compatibility with interrupt/\+syscall transitions
\end{DoxyItemize}

The descriptor layout is defined by Intel hardware and split into multiple packed bitfields. The CPU reconstructs the final descriptor values internally when the GDT is loaded.

In long mod:\+
\begin{DoxyItemize}
\item Base addresses are ignored for normal code/\+data segments
\item Segment limits are ignored
\item The L-\/bit inside the granularity field enables 64-\/bit code execution
\end{DoxyItemize}

64-\/bit Task State Segment GDT descriptor 

Represents the special 16-\/bit system descriptor used to reference an x86\+\_\+64 Task State Segment from the GDT.

Unlike normal segment descriptors, TSS descriptors occupy TWO consecutive GDT entries (16 bytes total).

The descriptor stores:\+
\begin{DoxyItemize}
\item Full 64-\/bits TSS base address
\item TSS structure size
\item Descriptor type metadata
\end{DoxyItemize}

The descriptor is loaded into the Task Register (TR) using the {\ttfamily ltr} instruction. \Hypertarget{group__CPU__SEGMENTATION_ga93e93abf00bffe42a08dd8900623b501}\index{CPU Segmentation \& Task State Management@{CPU Segmentation \& Task State Management}!TSSEntry@{TSSEntry}}

x86\+\_\+64 Task State Segment structure 

Defines the hardware Task State Segment (TSS) used by the CPU in x86\+\_\+64 long mode.

TSS is primarly responsible for:\+


\begin{DoxyItemize}
\item Ring 3 -\/\texorpdfstring{$>$}{>} Ring 0 stack switching
\item Interrupt Stack Table (IST) support
\item Dedicated exception recovery stacks
\item Syscall and interrupt privilege transitions
\end{DoxyItemize}

rsp0 field specifies the kernel stack pointer the CPU loads whenever execution transitions from user mode into kernel mode.

The Interrupt Stack Table (IST) allows specific interrupts to automatically switch to dedicated emergency stacks. This is commonly used for:\+


\begin{DoxyItemize}
\item Double faults
\item Non-\/maskable interrupts
\item Critical exception recovery
\end{DoxyItemize}

This structure layout is defined by Intel and must remain packed.
