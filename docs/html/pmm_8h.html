Detailed Description

Physical Memory Manager (Buddy Allocator) declarations.

This header defines a binary buddy memory allocator for managing physical page frames. It tracks free memory blocks using an intrusive circular doubly linked list per allocation order, supplemented by a bitmap tracking allocation states to prevent fragmentation and facilitate coalescing.
