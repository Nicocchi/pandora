Detailed Description

Core kernel initialization engine and execution entry point.

Author
Nicocchi
Date
May 28, 2026

Orchestrates early bare-metal platform bootstrapping over the Limine Boot Protocol. Manages the parsing of hardware tracking structs, initializes primitive debugging communication subsystems, bootstraps C++ global runtimes, structures font tables, and passes control off to the internal terminal environment.

void CallGlobalConstructors ( )
static

Executes initialization loops across early C++ static and global object constructors.

Iterates through the .init_array section populated by the compiler toolchain, safely calling each constructor function pointer sequentially before kmain triggers object interactions.

◆ hcf()

void hcf ( void )
static

Halts the CPU infinitely.

Issues the x86 hlt instruction to suspend execution until the next non-maskable or external hardware interrupt occurs. Wrapped inside an infinite fallback loop to prevent processor runaways.

void KernelPanic ( const char * str)

Triggers a critical system breakdown state, piping messages across diagnostic outputs.

Simultaneously dumps failure summaries across the serial COM1 port interface and onto the active linear graphical display before hanging the CPU execution chain.

void kmain ( void )

Main entry threshold for kernel runtime operations (called natively by Limine).

Performs early structural checks on bootloader response elements, initialises the primary 16550 UART serial connection, maps direct font rendering buffers, and draws text output routines onto the linear graphical display workspace.
