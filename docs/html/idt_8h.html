Detailed Description

Interrupt Descriptor Table (IDT) structures and interrupt handling definitions.

Author
Nicocchi
Date
May 29, 2026


Defines the core data structures used for x86_64 interrupt handling, including IDT gate descriptors, the IDTR register structure, and the interrupt stack frame passed from low-level assembly interrupt stubs into the higher-level C++ interrupt dispatcher.

The IDT is responsible for routing CPU exceptions, hardware IRQs, and software interrupts to their respective interrupt service routines (ISRs).
