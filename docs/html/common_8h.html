Detailed Description

Shared kernel constants and low-level architecture resources.

Provides globally shared constants, descriptor selectors, and architecture-level resources used throughout the kernel.

This header primarily contains:

  • GDT selector definitions
  • Privilege-level segment constants
  • Early kernel bootstrap resources
  • Shared low-level CPU infrastructure data

The selector values defined here correspond directly to the descriptor layout installed by the kernel Global Descriptor Table (GDT).

void hcf ( void )

Halts the CPU infinitely.

Issues the x86 hlt instruction to suspend execution until the next non-maskable or external hardware interrupt occurs. Wrapped inside an infinite fallback loop to prevent processor runaways.

Simultaneously dumps failure summaries across the serial COM1 port interface and onto the active linear graphical display before hanging the CPU execution chain.

uint16_t GDT_USER_DATA_RING3 = 0x1B
constexpr

User-mode selectors with Requested Privilege Level (RPL) set.

The lower two selector bits encode the privilege level requested by software. Ring 3 selectors are required during transitions into userspace execution.
