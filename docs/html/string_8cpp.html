bool CheckStringEndsWith ( const char * str,
const char * end )

Verifies whether a string ends with a specific trailing substring.

Extremely useful during boot operations to parse and validate filename extensions (e.g., checking for ".psf").

Parameters
[in]strThe base null-terminated target string to analyze.
[in]endThe expected suffix string to check against the end of str.
Returns
true if str safely terminates with the exact characters matching end, otherwise false.
