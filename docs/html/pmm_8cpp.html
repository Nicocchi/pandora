Detailed Description

Physical Memory Manager (Buddy Allocator) implementation.

Copyright
Copyright (c) 2026, Nicocchi @license Licensed under the GPL2 License
Author
Nicocchi
Date
May 31, 2026

Implements the core logic for the binary buddy allocator. This file contains private page-frame-number (PFN) helpers, bit-togglign routines for tracking buddy pairings, region feeding algorithms, and the primary allocation and coalescing code blocks.

Breaks down and distributes an arbitrary physical memory segment into the free lists.

Iteratively discovers the largest naturally aligned binary block sizes that fit within the segment boundaries, initializing individual list blocks dynamically inside the free pools.

Parameters
baPointer to the active allocator state context.
baseStarting raw physical address of the discovered memory segment.

void BuddyBitFlip ( BuddyAllocator * ba,
uint64_t pfn,
uint8_t order )

Toggles the allocation state bit shared between two adjacent buddy pages.

Uses an XOR bit-mask toggle strategy where a value of 0 indicates both buddies share an identical state (either both allocated or both free), enabling coalescing.

Parameters
baPointer to the active allocator state context.
pfnPage frame number index relative to the allocator base layout.
orderSize order layer scaling factor index.
