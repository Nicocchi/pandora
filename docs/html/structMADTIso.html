Detailed Description

MADT entry describing an Interrupt Source Override (type 2).

Interrupt Source Overrides describe differences between the IA-PC standard interrupt bus (ISA) and the actual hardware routing. For example, ISA IRQ 0 (PIT timer) is often physically wired to GSI 2 on the I/O APIC rather than GSI 0, and this entry records that remapping.

The flags field encodes polarity and trigger mode:

  • Bits 0-1: Polarity (00 = bus default, 01 = active high, 11 = active low)
  • Bits 2-3: Trigger mode (00 = bus default, 01 = edge, 11 = level)
Note
Must be parsed as a packed struct to avoid compiler padding.
