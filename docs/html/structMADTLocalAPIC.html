Detailed Description

MADT entry describing a Processor Local APIC (type 0).

One entry of this type exists per logical processor in the system. The flags field indicates whether the processor is enabled and available for use. Only processors with bit 0 of flags set should be considered active.

Note
Must be parsed as a packed struct to avoid compiler padding.
