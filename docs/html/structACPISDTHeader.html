Detailed Description

Common header shared by all ACPI System Description Tables.

Every ACPI table begins with this 36-byte header. The signature field identifies the table type (e.g., "APIC" for MADT, "FACP" for FADT).

Note
Must be parsed as a packed struct to avoid compiler padding.

https://wiki.osdev.org/ACPI
