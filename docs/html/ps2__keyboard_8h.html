void InitKeyboard ( )

Initializes the keyboard driver hardware and driver states.

Configures the keyboard controller, clears internal input buffers, and readies modifier toggle registers.

◆ KeyboardHandler()

void KeyboardHandler ( InterruptFrame * frame)

Top-half interrupt service routine wrapper for keyboard inputs.

Reads scancodes directly from the hardware I/O ports, processes state transitions, and posts events to the internal OS queue.

Parameters
framePointer to the processor context at the time of the interrupt.

Polls and pops the oldest event from the keyboard input queue.
